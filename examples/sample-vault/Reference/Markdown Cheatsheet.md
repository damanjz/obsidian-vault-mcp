# Markdown Cheatsheet

No frontmatter in this note.

- Wikilink: `[[Note]]`
- Alias: `[[Note|shown text]]`
- Heading link: `[[Note#Heading]]`
- Embed: `![[Note]]`

An external link is not a note link: [example](https://example.com).
Headings are not tags:

## Section heading

A number like #123 is not a tag, but #reference is.
